# v0.2.0 verification

## Pre-release run — 2026-09-25

Run on the release branch before publishing, on macOS (Darwin 25.5.0) with Node v26.4.0 and Docker 27.3.1 (Docker Desktop, linux/arm64 guests). CI repeats the unit, type, package and integration tiers on linux/amd64 with Node 22, 24 and 26 once the branch is pushed.

- **Unit:** `pnpm test`: 127 passed, 0 skipped. That is the 112 tests of the final 0.1.x main run plus 15 new ones covering the CLI (argument parsing, configuration, exit codes, secret redaction and every command against an in-memory store and scripted VMs), `FreestyleSandbox` (user, the 300 s exec cap, env forwarding, result mapping) and `createVolumeReadySnapshot` (builder VM options, bootstrap failures, cleanup, validation).
- **Type checks:** `pnpm check:types` passed against `freestyle@0.2.14`, now also assigning the real SDK client to `FreestyleSnapshotClientLike` and SDK firewall specs to `FreestyleFirewallSpec` in both directions. `pnpm check:examples` passed, including the new `examples/prepare-snapshot.ts`.
- **Package:** `pnpm test:package` passed. It packs the tarball, installs it into a fresh project with `freestyle@0.2.14`, imports every entry point (and `require()` of the root, since the runtime supports `require(esm)`), runs the installed `freestyle-volumes` bin, and type-checks a consumer under `nodenext` (with library checks), `bundler` and `node10`. `npm publish --dry-run` ran the same checks through `prepublishOnly` and listed 69 files (133.5 kB packed). `publint`: all good. `@arethetypeswrong/cli`: every entry point resolves under node10, node16 ESM and bundler; node16 CommonJS gets the expected ESM-only warning.
- **Integration:** `VOLUMES_TEST_BOOTSTRAP=1 pnpm test:integration`: 28 passed, 0 failed, 0 skipped. That is the 26 tests of the final 0.1.x main run plus the 2 new CLI tests, which drive the real bin through create, attach, write, inspect, detach, read-back from the bucket and delete on a real rclone FUSE mount, and check that failures exit 1. The suite still includes the bare `ubuntu:24.04` bootstrap, rclone 1.68.0 and 1.75.1, the small real multipart fixture and Git on real FUSE.
- **Freestyle live:** `pnpm test:freestyle`: 2 skipped. The round-trip test needs `FREESTYLE_API_KEY`, `VOLUMES_S3_BUCKET`, `VOLUMES_S3_ACCESS_KEY_ID` and `VOLUMES_S3_SECRET_ACCESS_KEY`; the snapshot test additionally needs `VOLUMES_TEST_PREPARE_SNAPSHOT=1`. **No live Freestyle round trip, snapshot build or pause/resume has been validated.** The manual Freestyle live test workflow runs both tests once the repository has the secrets.

The same boundaries as before apply. Docker results are not Freestyle results. Large multipart boundaries are mocked rather than copied for real (no 5 TiB copy). Git coverage is unit, local smart HTTP and real FUSE, not live authenticated GitHub. The snapshot helper is verified against the SDK's types and a scripted client; the Freestyle behavior it relies on (create, exec as root, snapshot of a running VM, delete, VM TTL) is documented by Freestyle but untested here.

Earlier runs, including the final 0.1.x main run of 2026-09-18 and the CI links for older revisions, are in [v0.1.md](v0.1.md).
